# 積木幻想：晶之迴響 · Brick Fantasy: Crystal Echoes

用積木搭成的回合制 RPG。玩法參考《FINAL FANTASY RESONANCE》：打弱點削減敵人的「防禦」、打中弱點可以多行動一次、讓敵人「破防」、累積「共鳴」放大招，還有裝備古代英雄之魂「迴響」的職業系統。劇情是原創的，共十二章，另外有破關後的內容。

**線上玩：** https://ywchen0711.github.io/brick-fantasy/

## 故事

千年之前，「虛無」吞噬了世界。最初的聆晶者把八位英雄的魂唱進了八顆水晶，水晶的歌聲從此守護著稜晶大陸。

白隼王國的見習騎士洛恩和薇拉第一次搭飛空艇出巡，就被一個戴著灰色王冠的騎士擊落。他們在峽谷裡遇見聽得見水晶聲音的少女小鈴。三個人追著灰冕騎士走遍大陸，一路查出水晶真正的秘密：那歌聲是被關住的英雄在哭。

## 戰鬥

- **時間軸**：畫面上方列出接下來的行動順序，速度越快輪到越多次。
- **弱點**：敵人頭上的「？」是還沒找到的弱點。打中之後就會亮出圖示。小鈴的「聆聽」能直接看穿弱點。武器分成斬、突、打、射四種，魔法有火、冰、雷、水、風、土、光、闇八種屬性。
- **額外回合**：打中弱點、或讓敵人破防的隊友，可以馬上再行動一次。
- **破防（BREAK）**：藍色的防禦條歸零時，敵人跳過下一回合，受到的傷害增加五成。
- **蓄力**：頭目蓄力時名牌會變紅，在牠出手前讓牠破防，這招就會被打斷。
- **共鳴**：打弱點、讓敵人破防都會累積共鳴（三格）。一格放「共鳴技」，也就是隊友裝備的迴響的奧義。兩格放「合體技」，需要兩位隊友各自裝備一對搭檔迴響。
- **自動／加速**：右上角的按鈕，練功時很好用。打輸時可以直接重打那一場。

## 迴響

二十四位古代英雄的魂，像職業一樣裝備在隊友身上。迴響會提升能力，給你新的技能、一個被動能力、一個共鳴技，還有一位合體技的搭檔。戰鬥中得到的 EP 會讓迴響升級（Lv1～10）。迴響升到 Lv10 就算精通，它的技能可以放進任何隊友的技能欄。

劍聖、火焰魔女、冰之巫女、雷神鬥士、潮汐祭司、風之舞者、大地守護者、聖女、暗黑騎士、聖騎士、龍騎士、盜賊王、神射手、拳聖、吟遊詩人、時魔導士、召喚師、機工士、忍者、賢者、舞孃、獸王，再加上兩位隱藏迴響。

## 其他

- **自動練功**：在野外或迷宮開啟後，隊伍會自己在附近走來走去打魔物，戰鬥也是自動的。血量或魔力太低時，會自己走去這張地圖的存檔水晶補滿再繼續；沒有水晶的地方會喝背包裡的藥水和鳳凰之羽，用完就停下來。不會走出地圖，也會避開劇情點和頭目。按任意方向鍵、B、選單鍵，或點畫面上方的牌子就會停止；換地圖或全滅也會停。

- **世界地圖**：可以騎奔奔鳥（跑得快、能越過流沙、不會遇敵），也能開船出海、駕駛飛空艇飛越山脈和海洋。
- **懸賞**：各城鎮的懸賞公會有 12 隻懸賞魔物。
- **支線任務**：城鎮的居民會拜託你事情，冒險日誌裡會記錄。
- **城鎮**：有商店、旅館和存檔水晶。存檔水晶也會幫隊伍完全回復。
- **魔物圖鑑**：收錄約 140 種魔物，打倒後會顯示弱點和掉落物。
- **設定**：可調難度（簡單、普通、困難）、遇敵率、文字速度、音量和景深效果。

## 怎麼做的

整個遊戲不用建置工具，也沒有圖片和音樂檔：場景、人物、特效和音樂全部用程式即時產生。

- `js/engine/voxel.js`、`js/brick/minifig.js`：積木方塊世界和積木小人。這兩個檔案沿用《武林積木》與《積木建造家》。
- `js/engine/mapgen.js`、`worldgen.js`：依照描述產生城鎮、野外、地下城、房間和整張世界地圖。
- `js/engine/field.js`：探索模式。斜俯角鏡頭、隊伍跟隨、碰撞、NPC、寶箱、存檔水晶和交通工具。被牆擋住的隊長會顯示成半透明剪影。
- `js/engine/battle.js`：戰鬥規則（不含畫面），`tools/sim.mjs` 用它在沒有畫面的情況下模擬整場頭目戰，用來調整數值平衡。
- `js/engine/battleview.js`、`fx.js`、`beasts.js`：戰鬥畫面、積木特效，以及四十多種用積木搭出來的魔物。
- `js/engine/audio.js`：合成音效，以及依照和弦進行即時作曲的配樂。
- `js/data/`：技能、角色、迴響、物品、魔物和地圖的資料表。
- `js/story/`：每一章的劇情、支線任務和頭目。
